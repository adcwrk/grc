# Framework Mapping

## Purpose

Map engagement scope and source material to applicable frameworks without hard-coding the repository around one framework.

## Required Behavior

- Use framework identifiers and mappings already present in the repository.
- Do not copy restricted framework text.
- Treat CMMC, NIST CSF, ISO, SOC 2, CIS, AI governance, data governance, and other frameworks as modular.

## Output

- mapping notes
- missing framework data questions
- recommended framework workspace initialization tasks
